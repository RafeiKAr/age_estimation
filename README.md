\## Altersrechner (Code Vibing Übung)



Ein kleines Python-Projekt zur Berechnung des exakten Alters in:



\- Jahre

\- Monate

\- Tage



Das Geburtsdatum wird im Format `TT.MM.JJJJ` eingegeben.



\## Beispiel



Eingabe:
01.01.1990



Ausgabe:

Sie sind 34 Jahre und 2 Monate und 5 Tage alt!





\##Ausführen

python main.py





\## Technologien



Python 3

datetime

calendar


# Ziel des Projekts

Dieses Projekt entstand als Übung im "Code Vibing" – exploratives, kreatives Programmieren mit Fokus auf Verständnis der Datumsarithmetik.
